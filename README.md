# BOBOBO — 音楽でダンス

ブラウザ内でマイクの音を解析し、推定したテンポに合わせてBOBOBOが踊ります。
Cloudflare Workers AIの設定なしで使えます。

## 使い方

1. HTTPSの公開ページ、または下記のローカルページを開く。
2. 「音楽でダンス」を押してマイクを許可する。
3. スピーカーで音楽を流す。規則的な拍を4拍以上検出すると、推定BPMを表示して踊り始める。
4. 画面右下の「ダンス → 激しく」で、ジャンプ・交互のキック・頭上の腕振りが加わる。「ふつう」で元に戻る。
5. 「マイク停止」で終了。「音に反応」へ切り替えると従来の音量反応になる。

ダンスの強さはマイク開始前にも選べます。切替でマイクを再取得したり、テンポをリセットしたりしません。
約1秒かけて動きを滑らかに切り替えます。激しいダンス中は少し引いた画角になり、停止すると戻ります。

上部の「BEAT」は、音楽モードで検出した音の立ち上がりごとに拍動します。
横長のレベルメーターと大きな0〜100の数値で、拍の強さを表示します。検出した立ち上がりの
強さを見やすく正規化した相対値で、音量のdB値やテンポ推定の信頼度ではありません。
バーと数値は拍の後に減衰し、無音・停止時は0に戻ります。
橙の「探索中」はテンポ推定前、青緑の「検出中」は規則的な拍を捉えている状態です。
無音では光が減衰し、マイク停止・音量モード・タブ非表示では「停止」になります。
推定BPMだけで自動点滅を続けるものではなく、追加の音声取得・AI通信も行いません。
OSの「視差効果を減らす」等の設定時は、拡大・波紋を抑えて明るさだけで反応します。

60〜200 BPMを目安に、低音の立ち上がりを重視して推定します。身体の上下動・
左右ステップ・首振り・腕の振りを拍に同期させ、振付を徐々に変えます。
無音では通常の動きに戻り、タブを隠すとマイクを停止します。戻った際は再度ボタンを押してください。
音声はブラウザ内だけで処理し、録音・保存・外部送信しません。この機能はAI APIを呼びません。
別途有効化した既存のWorkers AI行動選択は別機能です。

マイクが拾う音を使うため、ヘッドホン内の音楽や端末内の再生音を直接取得する機能ではありません。
拍が弱い曲、細かいリズム、環境ノイズでは倍・半分のBPMや誤検出になる場合があります。
曲や歌詞を理解するAIではなく、ローカルのビート検出と振付制御です。

## ローカル確認

```bash
npm ci
npm run serve
```

`http://127.0.0.1:4173/` を開きます。ビルド不要の静的サイトです。

```bash
npm test
npm run check
npm run typecheck
```

テストは既存の状態制御と追加したテンポ・ダンス・マイク制御を対象とします。
`check` は構文とローカルimport、`typecheck` は追加した4つの音楽用モジュールを確認します。
公開時は `index.html` と `src/` を同じ構成で配置してください。公開・Workerの変更は自動では行いません。

## 既存のCreature AI Workerについて

BOBOBOの行動候補をCloudflare Workers AIで低頻度に選ぶバックエンドです。
ブラウザへCloudflareの認証情報を置く必要はありません。

以下は従来のWorker開発メモです。このチェックアウトには `wrangler.jsonc` が参照する
`src/index.ts` が含まれていないため、Workerの開発・デプロイには元のWorkerソースが必要です。
音楽ダンスの静的サイト公開にはWorkerの再デプロイは不要です。

## 開発

```bash
npm install
npx wrangler dev
```

ローカルのGitHub Pages相当から接続する場合だけ、`wrangler.jsonc`の
`ALLOW_LOCALHOST`を`"true"`にします。本番では必ず`"false"`へ戻してください。

## デプロイ

```bash
npx wrangler deploy
```

デプロイ後のURLを`src/config.js`に設定するか、ページを`?debug=1`で開き、
開発パネルへ入力します。アカウントID、APIトークン、実URLはコミットしません。

Workers AIはローカル開発を含め、利用量に応じて課金または利用制限が発生する
可能性があります。Cloudflareダッシュボードで利用量を確認してください。

簡易レート制限はWorkerインスタンス内メモリを使うPoC用です。厳密な分散制限が
必要になった場合はCloudflare Rate Limiting bindingまたはDurable Objectsへ
置き換えてください。
